# Pigment — project context

Read by every AI tool working in this repository. `CLAUDE.md` imports this file, so Claude Code and Codex follow the same rules.

## What this is

**Pigment** is a Claude Code mod that shows, beside the chat, what AI work costs: each prompt, each task, each session, and for whoever runs the sprint, the sprint by task, who is working now and the time worked on each task. *How much paint went into each stroke.* It was written by Olegário Nascimento (Tech Lead and Engineering Manager), as the optional companion to [Brush Frame](https://github.com/Alcagoita/brush-frame).

Two views, picked in `/config` (**View**):

- **Your work** (developer): this prompt, this task, this session with how full the conversation is, and **Optimize now**, which writes a handoff so the work carries on in a fresh session.
- **The sprint** (manager): the team working now, the sprint so far, Worth a look (a task near or past its estimate, a quiet session), In development with time bars, by task, and a sprint summary file when the sprint ends.

## Layout

| Path | What it holds |
|---|---|
| `plugin/hooks/register.tsx` | The mod: events, the pane for both views, storage, the team server, Jira |
| `plugin/hooks/lib.ts` | Pure logic: costs, worked time, signals, Jira parsing, summaries (tested directly) |
| `plugin/hooks/figures.ts` | The pixel figures (manager, developer) as SVG and terminal cells |
| `plugin/types/index.d.ts` | The state contract (`Work`, `Sprint`, `TaskCost`, …) |
| `plugin/tests/pigment.test.tsx` | Tests for both views and every flow |
| `plugin/.claude-plugin/plugin.json` | The manifest, version and `/config` settings |
| `server/` | The optional team server: a Cloudflare Worker and D1 database, numbers only (`setup.sh` sets it up) |
| `assets/` | README artwork, generated by `make_assets.py` and `make_social.py` |

## How it works, in short

- **The ticket comes from the branch name** (`KAN-55-invite-link` → KAN-55).
- **Worked time** is each prompt's turn plus the reading and thinking before it when the gap is under 15 minutes; longer pauses don't count.
- **Where the numbers live** is chosen once per project in `.pigment/config.json`: on this computer (`.pigment/*.jsonl`, out of git) or the team's cloud.
- **Jira** comes through the Atlassian connector Claude Code is already signed in to: Pigment finds it by its tools, finds the site that knows the project, and reads the open sprint and logs worked time through it. The Jira settings in `/config` are only a fallback.

## Rules

- **Only numbers are stored**: ticket, session, display name, cost, tokens, time. Never prompts, answers or code.
- **Never see or print a key.** The team key lives in secure storage or `~/.pigment/keys/`; nothing reads it into a log, a toast or the chat.
- **Every change goes through a pull request into `main`**; merges happen only on the author's word. Bump `version` in `plugin.json` for each release.
- **The pane follows the drawing in `assets/views-*.svg`:** one surface split by thin lines, a figure on the right of each label, Worth a look in a soft amber box, bars in the task rows.
- **Voice:** calm and plain; the mod speaks in the first person. It never claims more than it measured: costs are local estimates at list price, and every picture of example numbers says so.
- **Write mods the engine's way:** functions that receive `$` are top-level; a press must return fast, so long work goes through `$.clock.after`.

## Checks before a pull request

- `claude plugin test plugin`: all tests pass
- `claude plugin validate plugin`
- Type-check with the generated `plugin/tsconfig.json` (`tsc -p plugin`)
- `node server/test.mjs` when `server/` changes
- Pane changes: look at both views in the desktop app, light and dark
